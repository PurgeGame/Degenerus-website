Degenerette regression fixtures
==============================

`degenerette-wild-vectors.json` is copied byte for byte from
`degenerus-audit/test/fixtures/degenerette-wild-vectors.json` (generated by
`degenerus-audit/scripts/data/degenerette_wild_vectors.py`, an independent
scalar reference verified there against the compiled contracts).
`degenerette-wild-vectors.test.js` pins its sha256 and replays every vector
through the site's reel, scoring, rig, payout and BoxSpin / DegeneretteResolved
decoders. Do not edit it here; recopy it from the audit repo.
